# AssaultXSS

A tool that's built for scanning XSS vulnerability on a website.

---

## Installation & Usage

```bash
git clone https://github.com/MatrixTM26/AssaultXSS.git
cd AssaultXSS
go build -o AssaultXSS AssaultXSS.go
./AssaultXSS -h
```
